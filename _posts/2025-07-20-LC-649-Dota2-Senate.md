Link: https://leetcode.com/problems/dota2-senate

Let's imagine how the process will be. We iterate over the senators again and again until there are only senators from one party. Pseudo code:

```
while radiant_count > 0 and dire_count > 0:
  for senator in senates:
    if senator is banned:
      continue
    else:
      # choose an opponent to ban.
```

Let's optimize this `for` loop first. Each round there will be half of the remaining senators banned, i.e., `N/2`, `N/4`... . Therefore, there will be `Log2N` rounds in total. The total complexity is `O(NLog2N)`. The question is: do we need to check every senator in each round? Can we just check the unbanned ones? Like we can have a container containing unbanned ones and a senator will be removed from the container once it's banned. Yes, it's like queuing up. Senators are in a line waiting to take action. If it's banned, it steps out of the line. If it's not banned, it goes to the end of the line and waits for another round. So the above `for` loop can be optimized to:

```
while radiant_count > 0 and dire_count > 0:
  cur = queue.popleft()
  if cur is not banned:
    queue.append(cur)
```

After being clear about how the rounds go, let's see what happens in each round. In each round, a senator will ban an opponent. Which opponent to ban? Since it plays the best strategy, it will ban the next closest opponent. For example,
```
R...D...R
```
If it's D's turn, it has 2 candidates to ban, R to its left and R to its right. If it bans left R, it will be banned by right R in this turn. If it bans right R, right R cannot ban it in this turn. 

"Finding the next opponent" makes us think of stack. Stack is used for problems to find the next something.

When iterating over the senators, at each position, we will check whether there's an opponent in the stack that can ban the current position. If the current position is banned, it's removed from the queue. Otherwise, we add it to the end of the queue.

So the code is:
```
class Solution:
    def predictPartyVictory(self, senate: str) -> str:
        rs = senate.count('R')
        ds = len(senate) - rs
        queue = deque(senate)
        stack = deque()

        while rs > 0 and ds > 0:
            cur = queue.popleft()
            if stack:
                if stack[-1] == cur:
                    queue.append(cur)
                    stack.append(cur)
                else:
                    stack.pop()
                    if cur == 'R':
                        rs -= 1
                    else:
                        ds -= 1
            else:
                stack.append(cur)
                queue.append(cur)
        return "Dire" if rs == 0 else "Radiant"
```

Finally, let's analyse the time complexity. As said above, the `while` loop will execute `LogN` times. Each time, queue size is halved. So to add up:
```
N + N/2 + N/4 + ... + 1 = O(N) 
```
(This is a common time complexity pattern.) 

The total time complexity is `O(N)`.
